2.  **차별화 포인트 확보:** 경쟁사가 모방하기 어려운, AI office만의 핵심적이고 독점적인 가치 제안을 확정합니다.
3.  **개발 우선순위 재조정:** '이 기능이 진짜 돈이 되는가?'에 대한 답을 얻어, 코다리가 개발할 기능의 우선순위를 명확하게 합니다.

**작성 목적:** 현 서비스 가설(Pricing_Model_Adjustment_Report.md 기반)의 유효성을 검증하기 위해, 시장 내 유사 경쟁사 3곳에 대해 표준화된 데이터 포인트를 수집합니다.

**적용 대상 (가정):**
1.  **경쟁사 A (글로벌 리서치 플랫폼):** 광범위한 데이터 제공 및 높은 비용 구조.
2.  **경쟁사 B (국내 금융 전문 서비스):** 특정 금융 상품에 특화된 깊이 있는 분석.
3.  **경쟁사 C (AI 기반 일반 리포팅 툴):** 사용 편의성과 자동화된 보고서 생성에 강점.

**필수 수집 데이터 포인트 (KPIs):**

| 카테고리 | 측정 지표 (Metric) | 세부 내용 (Details) | 분석의 목적 (Goal) |
| :--- | :--- | :--- | :--- |
| **1. Pricing & Monetization** | **티어 구조** | Free / Basic / Pro / Enterprise (제공되는 티어 목록) | 우리 서비스가 채택할 최적의 가격 모델 확정. |
| | **핵심 유료 기능** | 각 티어에서 유료로 제공되는 '결정적인' 기능 3가지 (예: 실시간 API 호출, 예측 모델, 전용 컨설팅) | 유료 전환을 유도하는 강력한 동기 부여 지점 식별. |
| | **사용 제한점 (Hard Limit)** | 무료/저가 티어에서 '절대 할 수 없는 것' (횟수, 데이터량, 시간 등) | 우리 서비스의 Free/Basic 티어의 훅(Hook) 설계. |
| **2. Feature Set (기능)** | **데이터 소스 범위** | 지원하는 데이터 유형 (주가, 뉴스, 거시 경제 지표, 산업 보고서 등) | 우리 서비스가 포괄해야 할 데이터 범위를 정의. |
| | **핵심 분석 기능** | 제공하는 분석 방법론 (예: 상관관계 분석, 시나리오 플래닝, 감성 분석) | '어떤 종류의 인사이트'가 시장에서 가장 가치를 인정받는지 확인. |
| | **사용자 인터페이스** | 리포트 시각화의 복잡도/간단함, 사용자 경험의 직관성 | UX/UI 설계의 난이도와 가치를 연계. |
| **3. User Experience & Value** | **가장 큰 페인 포인트** | 경쟁사 후기/리뷰에서 공통적으로 언급되는 '불만점' 또는 '아쉬운 점' | 시장이 아직 해결하지 못한 '빈틈(Gap)'을 찾아낼 기회. |
| | **UVP 요약** | 경쟁사가 스스로 정의하는 가장 강력한 한 줄 메시지 | 우리 서비스가 더 강력하게 주장해야 할 USP 정의. |
