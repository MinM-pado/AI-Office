### 💡 [결정된 작업] Tech-Engineering Lab 공식 디자인 시스템 구축
**목표:** 반도체 시장 분석, 전력망 자동화, 기술 보고서 등 모든 산출물에 일관된 전문성과 신뢰도를 부여하는 디자인 가이드 및 템플릿을 확립합니다.
**핵심 전략:** 기술적 복잡성(도면, 데이터)을 다루는 전문 기업의 특성을 반영하여, *데이터 시각화*와 *정보 계층 구조(Information Hierarchy)*에 최우선 순위를 둡니다.

### 🛠️ 결과물: 디자인 가이드 및 템플릿 구조화 (Markdown)

```markdown
# 📄 [브랜드명] 디자인 가이드: 기술 리포트 및 콘텐츠 템플릿

## 1. 색상 팔레트 (Color Palette)
| 용도 | HEX Code | 역할 |
| :--- | :--- | :--- |
| **Primary (메인)** | #004A99 | 신뢰, 전문성 (제목, 강조선) |
| **Secondary (보조)** | #FF9900 | 주목, 액션 (핵심 수치, 그래프 강조) |
| **Background (배경)** | #F5F5F5 | 가독성 확보 (본문 배경) |
| **Text (본문)** | #333333 | 기본 텍스트 색상 |
| **Accent (강조)** | #00A0FF | 기술적 강조 (코드 블록, 그래프 포인트) |

## 2. 타이포그래피 (Typography)
* **헤드라인 (H1):** Pretendard Bold, 32pt (강렬하고 전문적인 느낌)
* **서브헤드라인 (H2):** Pretendard SemiBold, 24pt
* **본문 (Body):** Pretendard Regular, 16pt (최대 가독성 확보)

## 3. 템플릿 구조 (Template Structure)

### A. 커버 페이지 (Cover Page)
* **구성:** 타이틀 (H1), 부제 (H2), 발표자/날짜, 회사 로고.
* **특징:** 배경에 은은한 기술적 패턴(Grid Pattern)을 적용하여 깊이감을 부여.
* **핵심:** 여백을 충분히 활용하여 고급스럽고 무게감 있는 인상 연출.

### B. 목차/개요 페이지 (TOC/Overview)
* **구성:** 목차(숫자화), 핵심 요약 3가지(Bullet Points).
* **특징:** 각 목차 앞에 해당 섹션의 대표 이미지를 작게 배치하여 시각적 흥미 유발.

### C. 본문 섹션 (Main Body Section)
* **섹션 제목:** (H2) Primary 색상으로 강조, 섹션 번호 (예: 2.1)를 앞에 붙임.
* **핵심 메시지 박스 (Key Insight Box):** 배경색을 연한 Secondary 색상으로 처리하고, 테두리를 Primary 색상으로 처리하여 독자의 시선이 머물게 함.
* **데이터 시각화:**
    * 그래프는 Primary/Secondary 색상을 명확히 구분하여 사용.
    * 설명 텍스트는 그래프 바로 아래에 배치하고, '핵심 해석'을 별도의 캡션으로 처리.

### D. 결론 및 Q&A (Conclusion & Q&A)
* **결론:** 가장 중요한 Takeaway 3가지를 다시 한번 요약하고, 각 항목에 대한 간결한 설명 추가.
* **Q&A:** 배경색을 배경색(F5F5F5)보다 약간 어둡게 처리하여 분리감 부여.
```
