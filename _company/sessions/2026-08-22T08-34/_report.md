<create_file path="~/Project/Business_Requirements_v2.md"># 💼 현빈: 비즈니스 요구사항 정의 (v2.0)

## 1. 배경 및 목표 재확인
본 문서는 'Pricing_Strategy_Hypothesis.md'에서 정의된 가설적 가격 모델을 기반으로, 실제로 구현 가능한 최소 기능 제품(MVP)의 구체적인 비즈니스 요구사항을 정의하는 것을 목표로 합니다. 핵심은 단순한 기능 나열이 아닌, **각 티어별로 고객에게 제공할 수 있는 고유의 '가치(Value)'**를 명확히 하는 것입니다.

## 2. 서비스 구조 (Service Tiers)
| 티어명 | 가격 (가정) | 핵심 가치 제안 (Value Proposition) | 주요 사용자 페르소나 |
| :--- | :--- | :--- | :--- |
| **Free (무료)** | 0원 | 시장 트렌드 요약 정보 및 기본 분석 (Low-effort Content) | 일반 투자자 (Curiosity) |
| **Premium (프리미엄)** | 월 $X | 핵심 기능 접근 (Deep Dive Analysis) + 데이터 연동 시각화 | 적극적 개인 투자자 (Active Trader) |
| **Enterprise (기업)** | 맞춤 견적 | 자동화된 리포트 생성 + API 연동을 통한 시스템 구축 | 전문 기관/팀 (Professional Firm) |

## 3. 기능 요구사항 (Feature Requirements)

### 3.1. Free Tier (핵심: 정보 제공)
*   **FR-01:** 실시간 시장 트렌드 요약 (최근 24시간 동안의 주요 지표 변화 요약). (데이터 소스: 공공 API)
*   **FR-02:** 핵심 키워드 기반 시장 뉴스 모니터링 및 요약. (데이터 소스: 웹 크롤링/뉴스 API)
*   **FR-03:** 기본 차트 조회 기능 (단순 OHLCV 차트).

### 3.2. Premium Tier (핵심: 심층 분석 및 맞춤화)
*   **FR-P1:** **[최우선] 개별 종목 심층 분석 보고서 생성.** (기존 가설 반영)
    *   포함 항목: 과거 5년 재무 데이터 비교, 특정 기간의 변동성 지표, 기술적 분석 (MACD, RSI 등) 시각화.
    *   *요구사항:* 사용자가 기간 및 종목을 선택하여 보고서 생성 버튼을 누를 때 작동.
*   **FR-P2:** **[핵심] 포트폴리오 위험도 시뮬레이션.**
    *   사용자가 보유 종목 목록을 입력하면, 가중 평균 위험도 및 분산 투자 효과를 계산하여 그래프로 제공.
*   **FR-P3:** **맞춤 알림 설정:** 특정 조건(예: 주가 5% 하락 시)을 설정하고 알림을 받을 수 있는 기능.

### 3.3. Enterprise Tier (핵심: 자동화 및 시스템 통합)
*   **FR-E1:** **API 키 발급 및 연동 서비스:** Premium Tier의 모든 분석 기능을 API 형태로 외부에 제공. (예: 자사 백엔드 시스템에 자동 연동)
*   **FR-E2:** **자동 리포트 스케줄링:** 지정된 시간에 맞춰 여러 종목/지표에 대한 분석 보고서를 PDF 형태로 자동 생성 및 이메일 발송.
*   **FR-E3:** **사용자 그룹 관리:** 다수의 사용자를 관리하고, 권한 및 접근 레벨을 세밀하게 제어하는 관리자 페이지.
